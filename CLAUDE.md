DayPilot is a student daily planner. Authentication uses Supabase Auth (free tier) — see src/lib/supabase.ts, which reads VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY from .env.local (gitignored; also set both in the Vercel dashboard for production). All routes except /login are behind the RequireAuth guard in src/App.tsx. App data (classes, goals, tasks, settings) currently still persists in localStorage through a single typed store module in src/store — this is being migrated to Supabase next; don't assume it's done. All AI calls go through src/services/ai.ts and use the USER'S OWN API key entered in Settings (Gemini free tier by default, Claude optional) — never hard-code any API key, never commit a key. The planner system prompt lives in src/prompts/plannerPrompt.ts and is the product's brain; it is tuned frequently. All JSON returned by AI must be parsed defensively (strip markdown fences, try/catch, offer retry). Mobile-first: design for 380px width first. No paid services beyond free tiers (Supabase, Gemini).
