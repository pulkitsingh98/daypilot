DayPilot is a student daily planner. All data persists in localStorage through a single typed store module in src/store. All AI calls go through src/services/ai.ts and use the USER'S OWN API key entered in Settings (Gemini free tier by default, Claude optional) — never hard-code any API key, never commit a key. The planner system prompt lives in src/prompts/plannerPrompt.ts and is the product's brain; it is tuned frequently. All JSON returned by AI must be parsed defensively (strip markdown fences, try/catch, offer retry). Mobile-first: design for 380px width first. No backend, no database service, no paid services.
